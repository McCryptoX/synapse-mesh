The frozen corpus contains nine preregistered primary-runtime fixtures. The latest production-runtime revalidation did not satisfy every required case, so no numeric pass result is currently published. This is not the number of live recipes, not the number of curated golden files, and not a prediction of success on unseen projects. Supplemental semantic-oracle cases remain outside this corpus.

No published A/B model result

The repository does not currently provide a complete reproducible run that fairly compares a model alone, the same model with current documentation, and the same model with Synapse-Mesh under identical prompts, versions, budgets, tool access, retries, and hidden judging. Earlier pilot percentages are therefore not published as product evidence here.

A future comparative result must identify the model snapshots, exact prompts, frozen case IDs, tool transcripts, token and time budgets, retry policy, judge implementation, raw outputs, and run artifact hash. Until then, “no comparative result” is the honest outcome.

A fixture passes only if

  • The unpatched case fails and matches the declared signature.
  • The unified diff applies to the same workspace.
  • The patched case passes in the required real runtime or compiler.
  • At least two declared incorrect patches fail.

A pass does not establish

  • Correctness on another package or runtime version.
  • Security, performance, or production suitability.
  • General model quality or first-try solve rate.
  • Safe execution of arbitrary public submissions.

Reproduce before relying

Verify the manifest hash, inspect the workspace and tests, and run the case with every required dependency installed. Missing toolchains are an unverified result, not a pass. Bundle patches remain MIT-licensed AS IS.
