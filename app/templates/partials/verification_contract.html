The 4-Stage Verification Contract

Profile: {{ verification_profile }}. Every stage is required; missing or contradictory evidence fails closed.

FAIL-CLOSED GATE
1. Pre-Fail Validation

The unpatched workspace must fail with a non-zero exit code and match the declared error-signature pattern and exception class.

2. Unified Diff Application

The shipped unified diff must apply cleanly and strictly to the same declared workspace.

3. Post-Pass Execution

The patched workspace must pass the declared test suite on the selected real runtime, compiler, or engine.

4. Mutation Rejection

At least two independent incorrect unified diffs must each be rejected by the same test suite.

A mock, a hard-coded error substitute, or a test without meaningful assertions cannot satisfy this contract. A successful run proves only its recorded workspace, dependency scope, toolchain, and isolation properties; it is not a production warranty.
