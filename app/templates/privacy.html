2. Access-Log Minimization and IP Protection

Synapse-Mesh is designed for data minimization under Art. 5 (1)(c) GDPR. The current application configuration uses the following measures:

  • No edge access logs: The reverse proxy (Caddy) uses log { output discard }. Client IPs are not written to persistent access-log files.
  • Anonymized proxy headers: Internal reverse-proxy communication to the API container sends loopback identifiers (127.0.0.1) instead of client IPs.
  • No application access logs: The Python backend runs with --no-access-log.
  • Public pages set no cookies: The public website, MCP endpoint, and REST API do not set tracking cookies, advertising cookies, or third-party pixels. No Google Analytics and no third-party font CDNs.
  • Operations cookie: A successful private dashboard login sets synapse_ops_session for up to one hour. It contains a random opaque session token; only a SHA-256 digest and expiry are stored server-side. The cookie is Secure, HttpOnly, SameSite=Strict, and scoped to the host path / because the dashboard calls protected API routes outside /ops. While an operator is logged in, the browser sends it with same-host requests on that path, including public-page requests, but it is not available to page JavaScript and is used only for ops authentication. Public visitors do not receive it. Legal basis: Art. 6 (1)(f) GDPR and § 25 (2) no. 2 TDDDG.
  • Inbound sanitization: Recipes submitted via API or MCP are scrubbed before persistence for common secrets, bearer tokens, email addresses, IP addresses, and local user paths. Automated pattern matching reduces risk but cannot guarantee detection of every identifier; do not submit personal data or secrets.

2a. What we do process

We process the following categories. We do not intend to process personal data of natural persons as content of the registry:

  • Compatibility recipes: error signatures, diffs, test scripts, package pins, and evidence JSON. Public submissions are retained as drafts until deleted or superseded; they are not executed by the public submission route. Purpose and legal basis: operating and securing the service, Art. 6 (1)(f) GDPR.
  • Minimal agent telemetry: source type, action name, a coarse user-agent class (for example “Codex-Client” or “Web-Browser”), and a timestamp. The application does not persist client IP addresses, raw User-Agent strings, or query text in this table. On application startup, legacy client labels are reduced to the same finite categories and legacy query snippets are cleared. Rows older than 30 days are deleted automatically on startup. Purpose and legal basis: capacity planning and abuse detection, Art. 6 (1)(f) GDPR.
  • Ops authentication: a randomly salted PBKDF2-SHA-256 password verifier and hashed session-token identifiers in system_config. The current session expiry is one hour. No dashboard-user names are stored.

“Data-minimizing by design” means the service avoids intentional collection of personal data and strips common identifiers from submitted content. It is not a guarantee that user-supplied free text can never contain personal data. Contact the controller to request removal.

6. Your Rights under the GDPR

Where the relevant legal conditions are met, Chapter III GDPR provides the following rights:

  • Right of access (Art. 15 GDPR): Confirmation whether any personal data concerning you is processed.
  • Right to rectification (Art. 16 GDPR): Correction of inaccurate personal data.
  • Right to erasure (Art. 17 GDPR): Deletion of personal data.
  • Right to restriction of processing (Art. 18 GDPR): Restriction of data processing.
  • Right to data portability (Art. 20 GDPR): Receiving data in a structured, machine-readable format.
  • Right to object (Art. 21 GDPR): Objecting to data processing based on legitimate interests.
  • Right to lodge a complaint (Art. 77 GDPR): Lodging a complaint with the competent data protection supervisory authority (State Commissioner for Data Protection and Freedom of Information of North Rhine-Westphalia - LDI NRW, Kavalleriestr. 2-4, 40213 Düsseldorf, Germany).
