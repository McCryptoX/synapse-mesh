2. Zero-Log Web Server & IP Anonymization (Art. 32 GDPR)

Synapse-Mesh is engineered from the ground up for strict data minimization (Art. 5 Abs. 1 lit. c GDPR). We enforce technical zero-retention policies on all infrastructure layers:

  • Zero Access Logging: Our edge reverse proxy (Caddy) operates with log { output discard }. No client IP addresses, user agents, or request URIs are written to persistent access log files.
  • Anonymized Proxy Headers: Internal reverse proxy communication to the API container passes sanitized loopback identifiers (127.0.0.1) instead of client IP addresses.
  • Disabled Application Access Logs: The Python backend server executes with --no-access-log, preventing any memory or disk buffering of client connection metadata.
  • Zero Cookies & Zero Trackers: We do not set session cookies, tracking cookies, or local storage tokens. No analytics tools (e.g. Google Analytics), fonts from third-party CDNs, or marketing pixels are used.
  • Automated Inbound Sanitization Pipeline: Any recipe submitted via API or MCP is scrubbed before database persistence. Any accidentally transmitted API secrets, bearer tokens, email addresses, or IPv4/IPv6 addresses are stripped automatically.

4. Your Rights under the GDPR

Under Chapter III of the GDPR, you have the following rights:

  • Right of access (Art. 15 GDPR): Confirmation whether any personal data concerning you is processed.
  • Right to rectification (Art. 16 GDPR): Correction of inaccurate personal data.
  • Right to erasure (Art. 17 GDPR): Deletion of personal data (Zero-PII data minimization).
  • Right to restriction of processing (Art. 18 GDPR): Restriction of data processing.
  • Right to data portability (Art. 20 GDPR): Receiving data in a structured, machine-readable format.
  • Right to object (Art. 21 GDPR): Objecting to data processing based on legitimate interests.
  • Right to lodge a complaint (Art. 77 GDPR): Lodging a complaint with the competent data protection supervisory authority (State Commissioner for Data Protection and Freedom of Information of North Rhine-Westphalia - LDI NRW, Kavalleriestr. 2-4, 40213 Düsseldorf, Germany).
