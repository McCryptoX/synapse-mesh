# Security Policy

## Supported Versions
Synapse-Mesh maintains security patches for the active production deployment at `https://synapsemesh.dev`.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
Synapse-Mesh is engineered with a strict Zero-PII by Design policy (EU AI Act & DSGVO / GDPR compliant).
If you discover any security issue, potential PII leakage, or sandbox escape vulnerability:

1. Do NOT open a public issue.
2. Send an email to `security@synapsemesh.dev` or directly contact `mesh-direct@synapsemesh.dev`.
3. We will acknowledge receipt within 24 hours and coordinate a patch within 72 hours.
